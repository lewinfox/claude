# claude

A sandbox for prototypes and half-formed ideas.

Each project lives in its own top-level subdirectory and is fully self-contained
— no shared code, dependencies, or root-level infrastructure. See
[CLAUDE.md](CLAUDE.md) for the ground rules.

## Projects

- [`tempo-lock/`](tempo-lock/) — detect the beats in a live-drummed track and re-time it to a fixed BPM (Beat This! + Rubber Band, FastAPI + canvas UI).
